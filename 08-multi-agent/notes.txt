Multi-Agent Design Pattern:
- Have multiple ai agents working together to achieve a common goal or task

- Group Chat Manager:
    - Every message is broadcasted to each agent
    - manager will select the appropriate ai agent to handle the task
    - Use CasesL Team Collaboration, customer support, social networking

- Handoff Pattern:
    - AI Agent completing each step in a defined workflow before passing it off to another AI agent
    - Use Cases: Customer Support, Task Management, Workflow Automation

- Collaborative Filtering:
    - Each ai agent in your application to perform a task
    - Example: Use wants a recommendation on the best stock to buy on the stock market:
        - Industry Expert: One agent could be an expert in a specific Industry
        - Technical Analysis: Another agent could be an expert in technical Analysis
        - Fundamental Analysis: Another agent could be an expert in fundamental analysis.
        By collaborating, these agents can provide a more comprehensive recommendation to the user

Example on why to use multi-agents:
Let's take an example, let's book a trip for a user. A single agent system would have to handle all aspects of the trip booking process, 
from finding flights to booking hotels and rental cars. To achieve this with a single agent, the agent would need to have tools for handling 
all these tasks. This could lead to a complex and monolithic system that is difficult to maintain and scale. A multi-agent system, on the other hand, 
could have different agents specialized in finding flights, booking hotels, and rental cars. This would make the system more modular, easier to 
maintain, and scalable.

Building Blocks on Implementing the Multi-Agent Design Pattern:
- Agent Communication: Agents need to communicate with each other to ensure that they are accomplishing the overall task
- Coordination Mechanisms: Coordinate their actions to ensure that the user's preferences and constraints are met
- Agent Architecture: Need to have the internal structure to make decisions and learn from their interactions with the user
- Visibility into Multi-Agent Interactions: Need to have visibility into how the multiple agents are interacting with each other (logging, mointoring, visualization, performance tools)
- Multi-Agent Patterns: There are different design patterns for implementing multi-agent systems (listed above)
- Human in the Loop: Need a human in the loop and need to instruct the agents when to ask for human intervention
